# 고령운전자 면허 반납 후 이동 공백 진단과 DRT 우선 지역 도출

2026 데이터안심구역 경진대회 (데이터+AI 혁신챌린지) · 2인 팀 · 2026.10

## 목적
고령운전자의 면허 자진반납은 빠르게 늘고 있지만, 반납한 뒤 차 없이 이동할 수단이 부족한 지역이 있습니다. 이 프로젝트는 **사고 위험, 자가용 의존, 대중교통 공급**을 함께 보고 이동 공백이 큰 지역을 찾은 뒤, 수요응답형 버스(DRT)를 먼저 검토할 지역을 제안합니다.

## 데이터

## 방법
1. **센터 안 집계** (`01_in_center_aggregation.ipynb`)
   - 74GB 차량등록 파일은 pandas `chunksize`로 100만 행씩 나눠서 집계했습니다.
   - 시군구 × 소유자 연령대 × 차종, 월 × 말소사유 표를 만들었습니다.
   - 3건 미만 칸은 비공개 처리했고, 개별 레코드와 정류장 좌표는 반출하지 않았습니다.
2. **전국 시군구 지수** (`02_sgg_index_and_maps.ipynb`)
   - 지표: 고령 사고(천 명당), 고령자 차량(백 명당), 버스 서비스권.
   - 각 지표를 백분위 순위로 바꿔 같은 가중치로 평균했습니다. 서로 상관이 0.93인 중복 지표는 뺐습니다.
   - 결과는 geopandas 단계구분도로 그렸습니다.
3. **공간 결합:** 정류장 178,452개 중 97.5%를 법정동에 연결했습니다. 전국 500m 격자 40만 개마다 가장 가까운 정류장까지 거리를 KD-tree로 구했습니다.
4. **수도권 604개 분석단위:** 법정동과 행정동이 1:1이 아닌 문제는, 서로 얽힌 동끼리 그래프 연결요소로 묶어 해결했습니다. 지표는 75세 이상 인구, 평일 버스 운행, 1인당 경로우대 승차입니다.
5. **견고성 확인:** 가중치·지표를 바꾼 6가지 계산 방식으로 순위를 다시 매겼고, 4번 이상 상위 20에 든 곳만 우선 지역으로 골랐습니다.

## 결과
- **전국 상위 15개 시군구:** 성주·영천·영암·양구·칠곡·충주·서귀포·진천·음성·장흥·연천·청도·증평·의성·군위
  - 축 하나를 2배로 가중해도 상위 15 중 11~13곳이 유지됐고, 버스 지표를 정류장 밀도로 바꾸면 14곳이 유지됐습니다.
- **수도권 DRT 우선 검토 9곳:** 광주 오포 일대, 고양 벽제, 고양 고봉, 용인 언남·청덕, 동두천 송내·지행, 광주 퇴촌, 양평 지평, 양평 강상, 강화읍
  - 9곳 중 **7곳은 기존 DRT 구역이 없습니다** (국토부 가이드라인 수록 사례 기준).
- **대표 사례, 광주시 오포 일대** (수도권 중앙값 대비): 75세 이상 인구 3.5배, 평일 버스 운행 0.5배, 경로 승차 0.2배, 정류장 주변 경사 1.7배
- **운영 근거:** 경로우대 승차의 55%가 09~15시에 몰리고, 60대 이상 평일 의료 이용의 91%가 08~17시, 87%가 5km 이내 → 평일 주간·생활권 중심 DRT
- **한계:** 서비스권이 면적 기준이라 산지 지역이 불리하고, 사고는 운전자 거주지가 아니라 발생지 기준입니다.
