# 고령운전자 이동 공백 분석

2026 데이터안심구역 경진대회 (데이터+AI 혁신챌린지) · 2인 팀 · 2026.10

## 분석 목적
고령운전자의 면허 자진반납은 빠르게 늘고 있지만, 반납한 뒤 차 없이 이동할 수단이 부족한 지역이 있습니다. 이 프로젝트는 사고 위험, 자가용 의존, 대중교통 공급을 함께 보고 이동 공백이 큰 지역을 찾은 뒤, 수요응답형 버스(DRT)를 먼저 검토할 지역을 제안합니다.

## 분석 과정
1. **센터 안 집계** (`01_in_center_aggregation.ipynb`)
   - 74GB 차량등록 파일은 pandas `chunksize`로 100만 행씩 나눠서 집계했습니다.
   - 시군구 × 소유자 연령대 × 차종, 월 × 말소사유 표를 만들었습니다.
   - 3건 미만 칸은 비공개 처리했고, 개별 레코드와 정류장 좌표는 반출하지 않았습니다.
2. **전국 시군구 지수** (`02_sgg_index_and_maps.ipynb`)
   - 지표: 고령 사고(천 명당), 고령자 차량(백 명당), 버스 서비스권.
   - 각 지표를 백분위 순위로 바꿔 같은 가중치로 평균했습니다. 상관이 높은 중복 지표는 제외했습니다.
   - 결과는 geopandas 단계구분도로 그렸습니다.
3. **공간 결합:** 정류장을 법정동에 연결했습니다. 전국 500m 격자마다 가장 가까운 정류장까지 거리를 KD-tree로 구했습니다.
4. **수도권 분석단위:** 법정동과 행정동이 1:1이 아닌 문제는, 서로 얽힌 동끼리 그래프 연결요소로 묶어 해결했습니다. 지표는 75세 이상 인구, 평일 버스 운행, 1인당 경로우대 승차입니다.
5. **견고성 확인:** 가중치·지표를 바꾼 6가지 계산 방식으로 순위를 다시 매겼고, 4번 이상 상위 20에 든 곳만 우선 지역으로 골랐습니다.

## 분석 결과와 한계

당시 분석에서는 전국 시군구별 이동 여건을 비교하고 수도권 DRT 우선 검토 지역을 선정했습니다. 세부 지역명과 집계 수치는 공개 가능 범위를 확인하기 전까지 이 문서에서 제외했습니다.

사고 발생지는 운전자 거주지와 다를 수 있고, 면적 기준 버스 서비스권은 산지 지역에 불리할 수 있습니다. 지표는 실제 면허 반납자의 이동 수요를 직접 측정한 값이 아닙니다.

## 저장소 구성
```
notebooks/
  01_in_center_aggregation.ipynb   # 센터 안 1차 집계 (사고·차량·말소, 소수 칸 비공개)
```

현재 포함된 코드는 1차 집계와 시군구 지수 분석입니다. 공간 결합, 후속 집계 및 민감도 분석 전체 코드는 아직 포함되지 않았습니다. 원본 데이터와 반출 집계표 없이 전체 결과를 재현할 수 없습니다. 코드 공개 조건은 별도로 확인해야 합니다.
